HTML block elements

A practical guide to the HTML elements commonly used to structure page sections, text, lists, forms, tables, and embedded content.

First, what is a block element?

“Block element” is a common learning term, not a formal category that includes every element below. Many of these elements have display: block by default: they start on a new line and usually take the available width. CSS can change that behavior, and some elements have special layout rules.

1. Page structure and landmarks

Use semantic elements to describe the role of different parts of a page.

<header>

Introductory content for a page or section, often a logo or heading.

<header>
  <h1>My site</h1>
</header>

<nav>

A section containing major navigation links.

<nav>
  <a href="/about">About</a>
</nav>

<main>

The dominant, unique content of the document. Usually one per page.

<main>
  <h2>Welcome</h2>
</main>

<section>

A thematic grouping of content, generally with a heading.

<section>
  <h2>Services</h2>
</section>

<article>

Self-contained content that could stand on its own, such as a post.

<article>
  <h2>News title</h2>
  <p>Story…</p>
</article>

<aside>

Related or complementary content, such as a sidebar.

<aside>
  Related links
</aside>

<footer>

Footer for a page or section, often containing author or legal info.

<footer>
  <p>© 2026</p>
</footer>

<address>

Contact information for the relevant article or page.

<address>
  Contact: hello@example.com
</address>

<div>

Generic container with no semantic meaning; useful for styling or layout.

<div class="card">
  Content
</div>

2. Text and content grouping

<h1>–<h6>

Six levels of headings. Use them in a meaningful hierarchy.

<h1>Page title</h1>
<h2>Section title</h2>

<p>

A paragraph of text.

<p>This is a paragraph.</p>

<blockquote>

A quotation from another source, usually displayed as an indented block.

<blockquote cite="https://example.com">
  A quoted passage.
</blockquote>

<pre>

Preformatted text that preserves spaces and line breaks.

<pre>
line one
  line two
</pre>

<hr>

A thematic break between paragraph-level sections; typically a horizontal rule.

<p>Part one</p>
<hr>
<p>Part two</p>

<figure>

Self-contained content such as an image, diagram, or code sample.

<figure>
  <img src="chart.png" alt="Sales chart">
  <figcaption>Sales</figcaption>
</figure>

<figcaption>

Caption or legend for its parent <figure>.

<figcaption>
  Figure 1: Results
</figcaption>

<dl>

Description list containing terms and their descriptions.

<dl>
  <dt>HTML</dt>
  <dd>Markup language</dd>
</dl>

<dt> and <dd>

A term/name and its description/value inside a description list.

<dt>CSS</dt>
<dd>Stylesheet language</dd>

3. Lists

<ul>

Unordered list, commonly shown with bullets.

<ul>
  <li>Tea</li>
  <li>Coffee</li>
</ul>

<ol>

Ordered list where sequence matters.

<ol>
  <li>Install</li>
  <li>Run</li>
</ol>

<li>

An item in an ordered or unordered list (and some menu lists).

<li>Learn HTML</li>

<menu>

A list of commands or menu items; in typical modern pages, it behaves much like a list.

<menu>
  <li>Save</li>
  <li>Print</li>
</menu>

4. Media and embedded content

<video>

Embeds a video player.

<video controls width="320">
  <source src="clip.mp4" type="video/mp4">
</video>

<audio>

Embeds audio content with optional playback controls.

<audio controls>
  <source src="song.mp3" type="audio/mpeg">
</audio>

<canvas>

Bitmap drawing surface controlled with JavaScript.

<canvas id="chart" width="300" height="150">
  Canvas not supported.
</canvas>

<iframe>

Embeds another HTML page within the current page.

<iframe title="Example" src="https://example.com">
</iframe>

<object>

Embeds an external resource, potentially with fallback content.

<object data="file.pdf" type="application/pdf">
  PDF unavailable.
</object>

<embed>

Embeds external content; support and use cases depend on the browser and resource.

<embed src="file.pdf" type="application/pdf">

5. Forms and interactive elements

<form>

Groups controls for submitting user-provided data.

<form action="/signup" method="post">
  <label for="email">Email</label>
  <input id="email" type="email">
  <button>Join</button>
</form>

<fieldset>

Groups related form controls, often with a legend.

<fieldset>
  <legend>Account</legend>
  <input name="user">
</fieldset>

<legend>

Caption for a <fieldset>.

<legend>Contact details</legend>

<label>

Caption for a form control. It is inline by default, but can be styled as block.

<label for="name">Name</label>
<input id="name">

<details>

Disclosure widget that users can open or close.

<details>
  <summary>More info</summary>
  Extra details here.
</details>

<summary>

Visible label for a <details> disclosure widget.

<summary>Show answer</summary>

<dialog>

Dialog box, such as a modal or non-modal dialog.

<dialog open>
  Dialog content
</dialog>

<output>

Displays the result of a calculation or user action; inline by default.

<output>42</output>

6. Tables

Table elements have their own layout model. They are structural elements, even though their display behavior is not the same as a normal block box.

<table>

Represents tabular data.

<table>
  <tr><th>Name</th><td>Asha</td></tr>
</table>

<caption>

Title or caption for a table.

<caption>Student marks</caption>

<thead>

Groups the header rows of a table.

<thead>
  <tr><th>Name</th></tr>
</thead>

<tbody>

Groups the main data rows of a table.

<tbody>
  <tr><td>Asha</td></tr>
</tbody>

<tfoot>

Groups footer rows, such as totals or summaries.

<tfoot>
  <tr><td>Total</td></tr>
</tfoot>

<tr>

A row of cells in a table.

<tr>
  <th>Subject</th>
  <td>HTML</td>
</tr>

<th> and <td>

Header cell and data cell. Their display is table-cell, not ordinary block.

<th scope="col">Name</th>
<td>Asha</td>

<colgroup> and <col>

Define groups of columns and column-level properties.

<colgroup>
  <col span="2">
</colgroup>

7. Other useful structural elements

<search>

Semantic container for search or filtering controls; block-level by default in browsers that support it.

<search>
  <form><input type="search"></form>
</search>

<noscript>

Fallback content shown when scripting is unavailable or disabled. Its display depends on context.

<noscript>
  Enable JavaScript for this feature.
</noscript>

<body>

Contains the document’s visible content. It is a document-level element, not a content section to repeat.

<body>
  <main>Page content</main>
</body>
Learning tip

Focus first on div, headings, p, lists, and semantic layout elements such as header, nav, main, section, article, aside, and footer. Then learn forms, tables, and embedded media. Not every element shown is technically a block-level element by default; check the element’s default display behavior when that distinction matters.
